# YouTube 推流说明

## 1. 创建 YouTube 推流目标

在 YouTube Studio 的直播控制室创建或选择直播，获取 Stream URL 和 Stream Key。常见 RTMP 地址为：

```text
rtmp://a.rtmp.youtube.com/live2
```

具体以 YouTube Studio 当前显示的地址为准。

**Stream Key 是秘密凭据。不要把它写进本仓库、截图或公开日志。** 只在 StreamBridge 管理界面中填写。

## 2. 在 StreamBridge 中配置

根据上游项目 README：

1. 在“推流目标”中添加 RTMP 地址和 Stream Key。
2. 在“视频推流”中选择本地视频文件或在线视频直链。
3. 选择推流目标。
4. 如需循环播放，启用循环选项。
5. 先进行短时间测试，检查视频、音频和推流状态。

## 3. 关于“定时直播”

上游 README 提到定时检测主播开播并自动转推，也提到视频文件循环推流；但目前不能仅凭 README 确认“指定日期/时刻自动启动和停止视频推流”是内置功能。

部署后需要在实际 Web 界面和当前版本中核实。如果没有原生定时任务功能，再评估服务器定时任务或外部调度方案。

## 4. 版权与平台规则

只推流自己拥有版权或已获得明确授权的内容。遵守 YouTube 直播、版权和变现政策；循环播放不代表可以绕过平台审核或变现要求。
